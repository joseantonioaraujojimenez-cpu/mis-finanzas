Importar movimientos de BBVA

Importa un archivo CSV descargado de BBVA. No existe conexión bancaria automática en esta versión.

Comprueba siempre la vista previa: el formato del CSV puede variar. Se evitarán duplicados con la misma fecha, importe, concepto original e identificador, cuando exista.

Copias de seguridad

Tus datos solo se guardan en este navegador. Si borras los datos de Safari o cambias de iPhone, podrías perderlos. Exporta una copia JSON periódicamente a Archivos o iCloud Drive.

Datos locales anteriores

Si tenías datos de Mis Finanzas v1.1 en este mismo navegador, puedes importar una copia JSON anterior. La importación reemplaza los datos actuales después de confirmar.
